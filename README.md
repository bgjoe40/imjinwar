# imjinwar — 임진왜란·정유재란 전쟁사 지도

1592년부터 1598년까지 이어진 임진왜란과 정유재란의 흐름을 지도 위에서 시간순으로 살펴보는 교육용 웹 프로그램입니다.
사건을 고르면 그 시점의 세력 판도와 각 세력의 현황이 바뀌고, 주요 전투는 게임처럼 부대가 움직이는 애니메이션으로 전개 과정을 보여 줍니다.

## 주요 기능

- **연대기 (왼쪽)** — 왜군의 부산 상륙(1592.4.13)부터 종전(1598.11)까지 주요 사건·전투 33개를 시기별로 정리했습니다. 육전·해전·공성·사건 구분과 승패 표시가 있습니다.
- **전략 지도 (가운데)** — 고른 시점의 거점별 조선 지배 / 일본 점령 상황, 진격로, 주요 군대 위치를 보여 줍니다.
- **세력 현황 (오른쪽)** — 조선(관군·의병·함선), 일본, 명의 병력·함선·군량·사기·거점 수와 지휘관, 역사적 의의를 보여 줍니다. 이전 사건과 비교해 늘고 줄어든 값을 ▲▼로 표시합니다.
- **전투 재생** — 23개 전투를 단계별로 재생합니다. 부대 이동, 사격·포격 효과, 실시간 병력 변화, 단계별 해설과 명언이 나옵니다. 재생/일시정지, 단계 이동, 속도(0.5~4배), 진행 막대를 쓸 수 있습니다.
- **1590년대 추정 지형** — 전투 화면 왼쪽 위의 [지형] 버튼으로 `현재`(위성 사진), `1590년대 추정`(고지도풍 지형), `비교`(좌우로 끌어 비교) 중에서 고를 수 있습니다. 매립 전 해안선, 성곽, 논·습지, 옛길을 덧그려 당시 지형을 짐작할 수 있게 했습니다.
- **연대기 자동 재생** — 상단의 `▶ 연대기 재생`으로 사건을 차례로 넘겨 볼 수 있습니다.

### 재생할 수 있는 전투 (23개)

| 시기 | 전투 |
| --- | --- |
| 1592 개전 | 부산진, 동래성, 상주, 탄금대 |
| 1592 반격의 시작 | 옥포, 사천, 한산도, 이치, 1차 평양성, 청주성 탈환, 부산포, 진주대첩(1차 진주성) |
| 1593 전세 역전 | 평양성 탈환, 벽제관, 행주대첩, 2차 진주성 |
| 1597 정유재란 | 칠천량, 남원성, 직산, 명량, 1차 울산성 |
| 1598 종전 | 사천(사로병진), 노량 |

## 실행 방법

빌드 과정이 필요 없는 정적 웹 페이지입니다. 지도 타일과 Leaflet 라이브러리를 인터넷에서 불러오므로 **인터넷 연결이 필요합니다.**

1. `index.html`을 웹 브라우저(Chrome, Edge 등 최신 브라우저)로 엽니다.
2. 또는 이 폴더에서 간단한 웹 서버를 띄운 뒤 `http://localhost:8765` 에 접속합니다.

```bash
python -m http.server 8765
```

### 조작법

| 동작 | 방법 |
| --- | --- |
| 사건 이동 | 왼쪽 목록 클릭, 상단 `◀ 이전` / `다음 ▶`, 키보드 ↑ ↓ |
| 전투 재생 | 사건 카드의 `⚔ 전투 전개 보기` 또는 목록의 `⚔ 전투 재생` 태그 |
| 전투 중 | Space 재생/일시정지, ← → 단계 이동, Esc 전략 지도로 돌아가기 |
| 지형 비교 | 전투 화면 왼쪽 위 [지형] → `비교`, 가운데 금색 막대를 좌우로 끌기 |
| 지도 배경 | 오른쪽 위 레이어 버튼: 위성 지형 / 지형도 / 고지도풍 |

## 파일 구성

```
index.html            화면 구성
css/style.css         스타일
js/data-events.js     사건 목록, 거점, 진격로, 세력 현황 데이터
js/data-battles.js    전투 시나리오 (부대, 단계별 위치·병력, 사격, 해설)
js/data-terrain.js    전투별 1590년대 추정 지형 (옛 해안선·성곽·논밭·옛길)
js/terrain.js         과거 지형 렌더링과 현재/과거 비교 기능
js/battle.js          전투 재생 엔진
js/app.js             전략 지도, 연대기, 세력 현황 패널
```

## 데이터 고치기·추가하기

코드를 몰라도 데이터 파일만 고치면 내용을 바꿀 수 있습니다.

- **사건 추가**: `js/data-events.js`의 `EVENTS` 배열에 항목을 넣습니다. `ch`에 거점 지배 변화(`'J'` 일본, `'K'` 조선), `f`에 세력 현황 수치를 적습니다.
- **전투 추가**: `js/data-battles.js`의 `BATTLES`에 전투를 만들고, 사건의 `battle` 항목에 그 이름을 적으면 연결됩니다.
  - `units`: 부대 목록 (`t` 병종 — `inf` 보병, `cav` 기병, `arq` 조총병, `gun` 화포, `ship` 함선, `turtle` 거북선, `flag` 지휘부, `castle` 성)
  - `phases[k].u`: 그 단계가 끝날 때의 `[위도, 경도, 병력]` (위치를 그대로 두려면 `null`)
  - `phases[k].fire`: `[공격 부대, 목표 부대, 종류]` (종류: `arrow`, `gun`, `cannon`, `fire`, `melee`)
- **과거 지형 추가**: `js/data-terrain.js`의 `PAST_TERRAIN`에 전투 이름으로 항목을 만들고 `water`(매립 전 바다), `walls`(성곽), `fields`(논밭), `roads`(옛길), `note`(설명)를 적습니다.

## 자료에 대한 안내

- 날짜는 한국 교과서 관례에 따라 **음력**입니다.
- 병력·함선·군량·사기 수치는 사료와 연구마다 차이가 큰 추정치를 교육용으로 단순화한 값입니다.
- 전투 속 부대 위치와 병력 변화는 기록을 바탕으로 전개 과정을 이해하기 쉽게 재구성한 것이며, 실제 배치와는 다를 수 있습니다.
- 지도의 세력 범위는 주요 고을을 기준으로 한 개략적인 표시입니다.
- **1590년대 추정 지형**은 오늘날 지도의 물길을 바탕으로 매립지·성곽·논밭 등을 덧그린 추정이며, 정밀한 역사 지리 복원이 아닙니다.
- 수업에 활용할 때는 교사나 전문가의 검토를 권장합니다. 잘못된 내용은 이슈로 알려 주세요.
