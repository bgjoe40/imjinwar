# imjinwar — 임진왜란·정유재란 전쟁사 지도

1592년부터 1598년까지 이어진 임진왜란과 정유재란의 흐름을 지도 위에서 시간순으로 살펴보는 교육용 웹 프로그램입니다.
사건을 고르면 그 시점의 세력 판도와 각 세력의 현황이 바뀌고, 주요 전투는 게임처럼 부대가 움직이는 애니메이션으로 전개 과정을 보여 줍니다.

**▶ 바로 보기: https://bgjoe40.github.io/imjinwar/**

## 주요 기능

- **연대기 (왼쪽 탭)** — 전쟁 전야(1590년 통신사)부터 전쟁 이후(1609년 기유약조)까지 사건·전투 53개를 시기별로 정리했습니다. 날짜는 음력이며 양력을 함께 적었습니다.
- **전략 지도 (가운데)** — 고른 시점의 거점별 조선 지배 / 일본 점령 상황, 진격로, 주요 군대 위치를 보여 줍니다. 오른쪽 위 레이어 버튼으로 **조선 8도(대략), 조선의 큰길, 남해안 왜성, 수군 본영의 이동, 의병 활동 지역**을 켜고 끌 수 있습니다.
- **세력 현황 (오른쪽)** — 조선(관군·의병·함선), 일본, 명의 병력·함선·군량·사기·거점 수와 지휘관, 역사적 의의, **근거 사료와 수치 범위**를 보여 줍니다.
- **전투 재생** — 37개 전투를 단계별로 재생합니다. 부대 이동, 사격·포격 효과, 실시간 병력 변화, 단계별 해설과 명언, **승패의 이유**가 나옵니다.
- **1590년대 추정 지형** — 전투 화면 왼쪽 위 [지형] 버튼으로 `현재`(위성 사진), `1590년대 추정`(고지도풍 지형), `비교`(좌우로 끌어 비교)를 고를 수 있습니다. 매립 전 해안선, 성곽, 논·습지, 옛길을 덧그렸습니다.
- **인물 사전** — 조선·의병·명·일본의 인물 71명. 생몰년, 직책, 활동, 관련 사건. 화면 곳곳의 지휘관 이름을 누르면 열립니다.
- **무기·전술 도감** — 판옥선·거북선·총통·비격진천뢰·조총·학익진·왜성 등 22개 항목을 그림과 함께 설명합니다. 전투 화면의 부대 아이콘을 눌러도 열립니다.
- **용어 풀이** — 정명가도·제승방략·훈련도감 등 51개 용어. 설명 글의 점선 밑줄 용어에 마우스를 올리면 뜻이 보입니다.
- **퀴즈** — 시기별 묶음에서 5문제씩 풉니다. 문제마다 해설과 관련 사건 바로가기가 있습니다.
- **전쟁의 결과** — 토지 결수 변화 도표, 인명·문화재 피해, 나라별 변화, 전쟁 뒤 연표.
- **공유 링크** — 주소 끝에 `#사건id`를 붙이면 그 사건이, `#사건id/battle`을 붙이면 그 전투가 바로 열립니다. 사건 카드와 전투 화면의 🔗 버튼으로 복사할 수 있습니다. (예: `https://bgjoe40.github.io/imjinwar/#e28/battle` → 명량 해전)

## 칠년전쟁 — 턴제 전략 게임 (`game/`)

같은 자료를 바탕으로 만든 코에이식 턴제 전략 게임입니다. 지도 프로그램과는 따로 동작하며, 지도 프로그램 상단의 🎮 게임 버튼으로도 들어갈 수 있습니다.

**▶ 바로 하기: https://bgjoe40.github.io/imjinwar/game/**

- **조선을 맡아** 1592년 4월부터 1598년 말까지 나라를 지킵니다. 일본과 명은 컴퓨터가 움직입니다. 시나리오는 `1592년 임진왜란`과 `1597년 정유재란` 두 가지입니다.
- **한 턴은 한 달**입니다(강화 협상기 1593~1596년은 석 달씩). 고을마다 장수에게 내정(개간·상업·축성·구휼), 군사(출진·징병·훈련·청야), 수군(함대 출진·판옥선·거북선 건조), 창의 독려, 원군 요청, 개혁(훈련도감·속오군·산성 수축 등)을 명령합니다.
- **전술 전투** — 육각형 칸 전장에서 부대를 한 턴씩 움직입니다. 읍성·산성·왜성 공방전, 야전, 해전이 있고 화공·혼란·고무 같은 계략을 씁니다. 기병은 평지에서 강하고 논·숲에서 약하며, 조선 활은 조총보다 멀리 쏩니다. 판옥선은 거리를 두고 총통을 쏘고, 일본 배는 붙어서 배에 오르려 합니다. 명량처럼 좁은 물목은 물살이 중간에 바뀝니다. `위임`·`즉시 결과`로 컴퓨터에 맡길 수도 있습니다.
- **보급과 의병** — 군사는 달마다 군량을 먹고, 같은 편 고을끼리 길로 이어지면 군량이 오갑니다. 조선 수군이 남해 바다를 지키면 일본의 서해 보급 뱃길이 끊기고, 의병은 점령지의 보급을 빼앗거나 고을을 되찾습니다.
- **역사 사건** — 의병 봉기, 선조의 피란, 명의 참전, 강화 협상, 2차 진주성, 이순신 파직과 칠천량, 명량, 도요토미의 죽음, 노량 같은 큰 사건은 실제 시기에 일어나고, 전투 결과와 점령지는 플레이에 따라 달라집니다. 사건 창과 전투 결과의 "실제 역사" 링크로 지도 프로그램의 해당 사건·전투 재생을 볼 수 있습니다.
- 진행은 브라우저에 자동 저장되고, 저장 칸 3개가 있습니다.
- 장수 능력치와 고을 수치는 게임을 위한 가상의 값이며 역사적 평가가 아닙니다.

```
game/index.html          게임 화면
game/css/game.css        스타일
game/js/game-geo.js      지도용 해안선·강·8도 경계 (Natural Earth, 자동 생성)
game/js/game-data.js     세력·고을·길·바다·장수 능력치·시나리오
game/js/game-core.js     게임 규칙 (명령, 출진, 경제·보급, 의병, 저장)
game/js/game-map.js      전략 지도
```

## 실행 방법

빌드 과정이 필요 없는 정적 웹 페이지입니다. 지도 타일과 Leaflet 라이브러리를 인터넷에서 불러오므로 **인터넷 연결이 필요합니다.**

1. `index.html`을 웹 브라우저(Chrome, Edge 등 최신 브라우저)로 엽니다.
2. 또는 이 폴더에서 간단한 웹 서버를 띄운 뒤 `http://localhost:8765` 에 접속합니다. 게임은 `http://localhost:8765/game/` 입니다.

```bash
python -m http.server 8765
```

## 데이터 고치기·추가하기

코드를 몰라도 데이터 파일만 고치면 내용을 바꿀 수 있습니다.

- **사건 추가**: `js/data-events.js`의 `EVENTS` 배열에 항목을 넣습니다. `ch`에 거점 지배 변화(`'J'` 일본, `'K'` 조선), `f`에 세력 현황 수치, `src`에 근거 사료, `range`에 수치 범위를 적습니다. `place`는 거점 이름이나 `[위도, 경도]`(이때는 `placeName`도 적음)로 지정합니다.
- **전투 추가**: `js/data-battles.js`의 `BATTLES`에 전투를 만들고, 사건의 `battle` 항목에 그 이름을 적으면 연결됩니다.
  - `units`: 부대 목록 (`t` 병종 — `inf` 보병, `cav` 기병, `arq` 조총병, `gun` 화포, `ship` 함선, `turtle` 거북선, `flag` 지휘부, `castle` 성)
  - `phases[k].u`: 그 단계가 끝날 때의 `[위도, 경도, 병력]` (위치를 그대로 두려면 `null`)
  - `phases[k].fire`: `[공격 부대, 목표 부대, 종류]` (종류: `arrow`, `gun`, `cannon`, `fire`, `melee`)
  - 승패의 이유는 `js/data-learn.js`의 `WHY`에 적습니다.
- **과거 지형 추가**: `js/data-terrain.js`의 `PAST_TERRAIN`에 전투 이름으로 항목을 만들고 `water`(매립 전 바다), `walls`(성곽), `fields`(논밭), `roads`(옛길), `note`(설명)를 적습니다.
- **인물·도감·용어·퀴즈**: 각각 `data-people.js`, `data-codex.js`, `data-learn.js`의 목록에 항목을 더하면 됩니다.
- 파일을 고친 뒤 `index.html`의 `?v=숫자`를 하나 올리면, 방문자 브라우저가 예전 파일 대신 새 파일을 받습니다.

## 자료에 대한 안내

- 날짜는 한국 교과서 관례에 따라 **음력**이며, 양력은 한국천문연구원 음양력 자료를 바탕으로 환산했습니다(자료에 따라 하루 정도 차이가 날 수 있음).
- 병력·함선·군량·사기 수치는 사료와 연구마다 차이가 큰 추정치를 교육용으로 단순화한 값입니다. 사건마다 근거 사료와 수치 범위를 적어 두었습니다.
- 전투 속 부대 위치와 병력 변화는 기록을 바탕으로 전개 과정을 이해하기 쉽게 재구성한 것이며, 실제 배치와는 다를 수 있습니다. 용인·웅치·이치·안골포처럼 정확한 위치에 여러 견해가 있는 전투는 화면에 추정임을 밝혔습니다.
- 지도의 세력 범위와 조선 8도 경계는 개략적인 표시입니다. 8도 경계는 오늘날 행정 구역을 바탕으로 했기 때문에 당시 경계와 다른 곳이 있습니다.
- **1590년대 추정 지형**은 오늘날 지도의 물길을 바탕으로 매립지·성곽·논밭 등을 덧그린 추정이며, 정밀한 역사 지리 복원이 아닙니다.
- 수업에 활용할 때는 교사나 전문가의 검토를 권장합니다. 잘못된 내용은 이슈로 알려 주세요.
